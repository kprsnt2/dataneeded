# Application Answers — verified facts for ATS form questions

> **Fill this in yourself.** These are the questions every application form asks
> and that cannot be derived from the resume. The packager reads this file and
> fills the question sheet; anything left as `<...>` is reported as OPEN and must
> be answered by you at submit time.
>
> Nothing here is ever guessed. A blank box you fill beats a plausible invention,
> and the `applications` stage has no submit path — see `jobagents/applications.py`.

## Rules for editing this file

1. Only statements that are literally true. This file is ground truth, exactly
   like `config/profile.md`.
2. Leave a value as `<...>` to keep it OPEN rather than guessing.
3. Do not add salary figures you have not decided to disclose — a blank answer is
   acceptable to most ATS forms; a wrong one is not.
